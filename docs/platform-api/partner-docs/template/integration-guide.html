01 · The idea

Replace the code-and-Drive handoff with a branded delivery

Today a finished job ends with a one-time code and a Google Drive link. With ShootPortal, the {{partner.contributor}} uploads inside {{partner.app}}, the {{partner.recipient}} opens a private {{partner.name}}-branded portal, and {{partner.name}} is told about every step automatically.

B

Principles we're designing around

{{icon "hand" 13}}

{{partner.name}} stays in control

Jobs, chat, payments and the client relationship stay in {{partner.name}}. ShootPortal is the delivery layer only. No quotes, invoices or payment screens appear anywhere.

{{icon "palette" 13}}

Branded end to end

Upload screen, portal and emails use {{partner.name}}'s name, logo and colors, with a small “Powered by ShootPortal” mark.

{{icon "hard-drive-upload" 13}}

Built for big files and bad signal

Uploads go in small chunks straight to secure storage. If the connection drops or the app closes, it resumes instead of starting over.

{{icon "lock-keyhole" 13}}

Private by default

Every link is private and expires. Secret keys never touch a phone. Every status message is signed so {{partner.name}} can trust it.

{{icon "repeat" 13}}

Works for marketplace and white-glove jobs alike. The same delivery can be created automatically by {{partner.name}}'s app, or by {{partner.name}} staff signing in to ShootPortal directly for hand-managed enterprise jobs.

In one sentence
{{partner.name}} keeps the job, the chat and the client relationship. ShootPortal quietly handles the files: upload, storage, a beautiful branded handoff, and a signed receipt for every step.

04 · Who does what

A small build for {{partner.name}}, the heavy lifting on ShootPortal

{{partner.name}}'s team builds

1

Create the job in ShootPortal

One server call when a job is accepted or completed (your choice).

2

The “{{partner.button}}” button

Ask ShootPortal for an upload link and open it in the app's in-app browser.

3

A status receiver

A small endpoint that checks each update's signature and moves the job forward.

4

Optional: share the link in chat

If {{partner.name}} prefers to message the {{partner.recipient}} itself.

ShootPortal provides

  • The API, a full test sandbox and test keys
  • The branded, resumable upload screen (phone and desktop)
  • Secure storage for every file type, {{pricing.retentionDays}} days included
  • The private, branded {{partner.recipient}} portal and emails
  • Signed, automatically retried status updates
  • Developer Guide, API reference and a Postman collection
  • A live demo partner to try the full flow before writing code
  • Direct founder support during integration

A

Security & privacy

  • Secret keys stay on {{partner.name}}'s servers. Phones only ever get a one-job, short-lived upload link.
  • Signed status updates. Each message carries a tamper-proof signature {{partner.name}} verifies.
  • Private, expiring links for every {{partner.recipient}}; files are never public.
  • Isolated data. {{partner.name}}'s jobs live in their own walled-off space.
  • Minimal data. Names and emails only. No prices, payments or job financials.
